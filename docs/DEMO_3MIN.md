**Meta gate:** The current run has only mocked API contract tests and authored offline dialogue. Do not call this a Meta-powered demo or submit it as clearing Stage One. **Recording:** `npm run demo:record:authored` records an actual local Chromium journey using CDP frames and system `ffmpeg`. The existing clip was captured at 1280×720 in Chromium 154 with SwiftShader. It contains the recording-only label `LOCAL CAPTURE · AUTHORED OFFLINE · META DISABLED`; the label is not an in-game feature. `ffprobe` confirmed H.264, 1280×720, 119.16 seconds, 1,762,745 bytes; full decode passed, but Chromium produced only 87 frames (~0.73 fps), which is visibly choppy. A bounded lower-cost screencast diagnostic at 640×360 with immediate acknowledgements reached only 1.40 frames/sec; the same SwiftShader scene ranged from 20 FPS before capture to 12 while capturing and 8 after a quiet window. These are variable software-renderer observations and do not isolate a repeatable recorder penalty. Treat the clip only as a local rehearsal/frame-review artifact, not the three-minute target video, a live Meta demonstration, hardware benchmark, or published deliverable. It recorded zero Meta requests, off-origin requests, page errors, console errors, HTTP errors, or guest vault writes. Three extracted frames were inspected at 1889, the 2087 consequence, and the beginning state; see the runbook. A separate earlier app sample near 4 FPS is not the MP4 frame rate.
