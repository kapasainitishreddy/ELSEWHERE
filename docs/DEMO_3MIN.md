**Meta gate:** The current run has only mocked API contract tests and authored offline dialogue. Do not call this a Meta-powered demo or submit it as clearing Stage One. Replace the authored-preview segment only after an explicitly authorized, successful live synthetic request and capture the actual user-facing behavior. A live handler call alone still does not prove a public deployment works.

**Recording:** `npm run demo:record:authored` records an actual local Chromium journey using CDP frames and system `ffmpeg`. The latest clip was captured at 1280×720 in Chromium 154 with SwiftShader and includes a recording-only `LOCAL CAPTURE · AUTHORED OFFLINE · META DISABLED` label; this is not an in-game feature. `ffprobe` confirmed H.264, 79.64 seconds, 1,825,549 bytes and 115 frames; full decode passed. Four stills at 8, 24, 48 and 70 seconds were inspected. The moving scene is visibly choppy at about 1.44 fps. A lower-cost 640×360 diagnostic reached only 1.40 fps; separate SwiftShader frame-rate samples varied from 20 before capture to 12 during it and 8 afterward. These variable observations do not isolate a repeatable recorder penalty. Treat the MP4 as a local rehearsal only, not a three-minute target video, live Meta demonstration, hardware benchmark, or published deliverable. The recorder asserted zero Meta requests, off-origin requests, page errors, console errors, HTTP errors, or guest vault writes. The Windows procedure is documented but has not been exercised on the owner's PC.
