# Director's Cut visual pass 1.2

The original in-game layout has been polished for stronger visual composition. The five portal thumbnails now show first-party illustrated environments rather than generic icon backgrounds. The focus view has an explicit Return to the Story control. The big introductory title now collapses after starting to move on desktop so the game scene remains readable; opening the story or atlas restores the interface. Each world has a more cinematic atmospheric wash, calibrated for small screens and reduced-motion settings.

No remote images or fonts have been added. Your encrypted state, future-self messages and time economy have not changed. This is an interface improvement, not an independently verified Quest graphics upgrade. The illustrations remain fallback art, not screenshots of 3D gameplay.

## Checks

Run `npm install && npm run check` on a connected machine. In a browser, verify all five portal cards, Return to the Story, atlas, side story sheet, keyboard navigation, and viewport sizes 390x844 / 1600x900. Then check real Quest comfort, controller input and frame rate separately. No background camera motion was added to VR.
