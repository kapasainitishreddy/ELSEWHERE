# Meta causal exhibit: actual model-directed, reversible 3D presentation

With explicit Meta Cloud consent, the supported Muse Spark reply format includes a third JSON field `focus` with one of `people`, `infrastructure`, or `memory`. The server and browser independently validate this literal choice. A successful response creates a small physical exhibit near the imagined older self; its label, miniature figures/towers/archives, and historical facts come from the authoritative game state. The model never receives a passphrase, memory cards, private letter, or other timeline, and cannot change inventory, credits, trust or outcomes.

The full visual response is more than an AI dialogue box, but it is NOT autonomous world generation. It is a **three-way constrained model-driven viewpoint**. If Meta is unavailable, authored dialogue continues and no model-selected exhibit is fabricated. On repeated conversations, old exhibit meshes and textures are disposed; on scene change the exhibit is removed. Reduced motion disables the ambient ring oscillation.

Tests: `npm run meta:check` and `npm test`. The full build and real Meta credential-backed execution must be verified before declaring a competition-ready app. Never present mocked JSON as evidence of live Meta AI.
