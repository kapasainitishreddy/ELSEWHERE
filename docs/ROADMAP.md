# ELSEWHERE — Development roadmap

The MVP is a playable browser-first narrative simulation with five connected environments. Below are **planned expansions**, not features already implemented.

## 1. Deeper living world
- Reusable world-file format with locations, people, laws, economies, quests and persistent memory.
- State graph for causal propagation with invariants and time progression.
- NPC daily schedules, attitudes and relationships that evolve beyond player dialogue.
- Nonlinear branching histories and multiple inventor decisions per life, with resource and plausibility constraints.
- World editor for user-written fantasy realms, sci-fi cities and educational historical settings.

## 2. Mechanical experiences
- Mech cockpit, first-person pilot controls, two-handed VR controls, locomotion comfort settings and enemy physics.
- Dungeon encounter AI, spells with cooldowns, object interaction and balanced quest systems.
- City commerce with businesses, ownership, investments and lifecycle simulation; separate in-game currencies from real money.
- Quest and ability progression independent of account monetization.

## 3. Immersion and accessibility
- Meta Immersive Web SDK integration from an official starter, native controller grabbing and locomotion.
- Physical Quest headset tests, simulator QA, comfort options, seated mode and motion-sickness reduction.
- Original licensed GLB assets, shader passes, VFX, PBR materials, animation rigs, spatial audio and accessible non-VR fallbacks.
- Efficient loading, level-of-detail, reduced-motion option, mobile touch navigation and multilingual subtitles.

## 4. AI, trust and authorship
- Meta Muse Spark live agent dialogue grounded in persistent fictional character state.
- Structured narrative planner that emits proposal events; deterministic state validator accepts/rejects changes.
- Browser privacy controls, opt-in memories, delete/export tools, transparent cost and provider toggles.
- Future-self as speculative roleplay, not mental-health advice, real prediction or personality assessment.
- Wider testing for prompt injection, moderation, adversarial character instructions and latency.

## 5. Measurement before launch
- Record completion rate of 10-minute playable loop, cold-start time, frame rate, VR sickness incidents and user comprehension.
- Add a separate automated accessibility audit and device/browser matrix without relying on GitHub Actions.
- Privacy and security review before any real user data, profiles or cloud accounts are introduced.
